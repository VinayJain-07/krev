# Citation and Claim QA

## Purpose

Make every decision-relevant statement auditable. This is a quality-control pass, not a writing pass: preserve useful claims, repair weak attribution, and clearly label what cannot be established.

## Process

1. Extract material claims: numbers, rankings, competitor descriptions, performance assertions, causal explanations, customer or audience statements, and recommendations presented as facts.
2. Classify each claim as direct website observation, official API result, timestamped public-web discovery, connected first-party data, or hypothesis.
3. Attach the strongest available source URL immediately beside the claim. Record access date, source owner, relevant page or field, and freshness.
4. Check that the source actually supports the wording, scope, time period, geography, and level of certainty. Downgrade or rewrite claims that overreach.
5. Flag unsupported numbers, implied causality, unnamed competitors, stale sources, and conclusions drawn from missing evidence.
6. Add a source register and a known-unknowns section. For every unresolved gap, name the next validation action or connector required.

## Output standard

Return an evidence ledger containing claim, source, source type, freshness, confidence, limitation, and required follow-up. Never hide an unsupported claim behind confident prose and never invent a citation.
