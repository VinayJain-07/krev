# Competitive Landscape Matrix

## Purpose

Create a comparable, source-led view of direct, adjacent, and indirect alternatives without turning public marketing language into invented market intelligence.

## Process

1. Define the comparison frame: customer job, category, geography, decision stage, and what counts as a competitor.
2. Select named companies only when a current, direct source supports inclusion. Expand to adjacent alternatives when the direct set is too small and label the relationship.
3. Capture the same dimensions for every company: category, audience, use case, offer, positioning, proof, content posture, channel presence, and apparent whitespace.
4. Preserve the official website URL, source date, exact evidence summary, and confidence for each row.
5. Separate observed positioning from strategic interpretation. Mark unverified revenue, market share, traffic, spend, customer sentiment, and performance as unknowns.
6. Convert repeated contrasts into implications, then list the smallest validation test for each proposed whitespace or differentiation opportunity.

## Output standard

Produce a matrix with one consistent row per company, followed by evidence-backed patterns, unresolved unknowns, and testable strategic implications. Never fabricate competitor names or quantitative market estimates.
