# Visual Report Composition

## Purpose

Shape evidence into a readable decision document whose hierarchy, tables, and visuals improve prioritization rather than decorate the page.

## Process

1. Define the reader, decision, evidence density, and expected next action before choosing a layout.
2. Open with the executive recommendation, the most important non-obvious finding, and the evidence boundary.
3. Use scorecards for repeated metrics, matrices for comparable fields, timelines for sequence, quadrants for impact versus effort, and decision cards for explicit choices.
4. Keep each visual tied to a decision. Do not create charts from one number, infer precision from qualitative evidence, or use decorative whitespace to hide thin analysis.
5. Include compact source notes at the point of use and a complete source register at the end.
6. Check page density, heading hierarchy, table readability, contrast, wrapping, and export behavior in HTML, PDF, DOCX, and XLSX.
7. Use Markdown tables only inside documents; agent feeds should use readable cards or short lists instead.

## Output standard

Return a structured report plan or finished document with section purpose, headline finding, evidence, decision, owner, metric, and source note. Every visual must make the recommended action easier to understand.
